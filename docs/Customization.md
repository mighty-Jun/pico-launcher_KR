# 사용자 지정 (Customization)
Pico Launcher는 SD 카드의 정해진 위치에 파일을 넣어 파일과 폴더에 사용자 지정 아이콘, 배너, 커버 이미지를 표시할 수 있습니다. 세 가지 모두 같은 폴더 구조를 따릅니다: nds 및 gba 파일은 게임 코드별로, 사용자 파일은 파일 이름별로 지정하며, 폴더 단위로도 지정할 수 있습니다.

## 아이콘 (Icons)
사용자 지정 아이콘은 `.bmp` 파일입니다. DS 롬은 이미 내부 배너의 아이콘을 표시하므로, 사용자 지정 아이콘은 주로 GBA 롬이나 다른 종류의 파일에 유용합니다.

### 게임 코드별 아이콘
`/_pico/icons/nds/` 또는 `/_pico/icons/gba/` 폴더에 `<게임코드>.bmp` 파일을 넣습니다. 예:
- `/_pico/icons/gba/ABCD.bmp` - 게임 코드가 `ABCD`인 GBA 게임의 아이콘
- `/_pico/icons/nds/EFGH.bmp` - 게임 코드가 `EFGH`인 NDS 게임의 아이콘 (롬 내장 배너 아이콘보다 우선)

### 사용자 아이콘 (파일 이름별)
`/_pico/icons/user/` 폴더에 `<파일이름>.bmp` 파일을 넣습니다. 예를 들어, `myGame.gba.bmp`는 파일 이름이 `myGame.gba`인 모든 파일에 사용됩니다. 이 설정은 게임 코드 기반 아이콘과 DS 롬의 내장 배너 아이콘보다 우선순위가 높습니다.

### 폴더 아이콘
아이콘을 지정할 폴더 안에 `icon.bmp` 파일을 직접 넣습니다. 예:
- `/GBA Games/icon.bmp` - `GBA Games` 폴더의 아이콘
- `/GBA Games/Racing/icon.bmp` - `Racing` 하위 폴더의 아이콘

각 폴더의 `icon.bmp`는 서로 독립적이므로, 이름이 같은 두 폴더에 서로 다른 아이콘을 지정할 수 있습니다. `.bmp` 파일은 롬 형식이 아니므로 `icon.bmp`는 롬 브라우저에 표시되지 않습니다.

같은 위치에 `banner.bnr` 파일([폴더 배너](#폴더-배너) 참조)을 넣어 폴더 아이콘으로 쓸 수도 있습니다. `banner.bnr`과 `icon.bmp`가 모두 있으면 `banner.bnr`이 우선합니다.

### 아이콘 우선순위
사용자 아이콘(`/_pico/icons/user/`) > 게임 코드 기반 아이콘(`/_pico/icons/nds/` 또는 `/_pico/icons/gba/`) > 내장 배너 > 테마 기본값.
폴더 아이콘은 위 우선순위와 별개로 찾습니다: `banner.bnr` > `icon.bmp` > 테마 기본값.

### 아이콘 형식
아이콘은 **32×32 픽셀, 4 bpp(16색), 비압축 `.bmp`** 파일이어야 하며, 팔레트의 첫 번째 색은 투명색으로 처리됩니다.

## 배너 (Banners)
사용자 지정 배너는 게임 제목, 부제목, (애니메이션) 아이콘을 담은 `.bnr` 파일입니다. GBA 롬이나 다른 시스템의 롬에 사용자 지정 제목과 (애니메이션) 아이콘을 붙일 때 특히 유용합니다.

### 게임 코드별 배너
`/_pico/banners/nds/` 또는 `/_pico/banners/gba/` 폴더에 `<게임코드>.bnr` 파일을 넣습니다. 예:
- `/_pico/banners/gba/ABCD.bnr` - 게임 코드가 `ABCD`인 GBA 게임의 배너
- `/_pico/banners/nds/EFGH.bnr` - 게임 코드가 `EFGH`인 NDS 게임의 배너 (롬 내장 배너보다 우선)

### 사용자 배너 (파일 이름별)
`/_pico/banners/user/` 폴더에 `<파일이름>.bnr` 파일을 넣습니다. 예를 들어, `myGame.gba.bnr`은 파일 이름이 `myGame.gba`인 모든 파일에 사용됩니다.

### 폴더 배너
배너를 지정할 폴더 안에 `banner.bnr` 파일을 직접 넣습니다. 예:
- `/GBA Games/banner.bnr` - `GBA Games` 폴더의 사용자 지정 배너

폴더에 사용자 지정 아이콘(정지 또는 애니메이션)이 붙고, 폴더 이름이 표시되는 모든 곳에서 배너의 제목이 대신 표시됩니다. SD 카드의 실제 폴더 이름(탐색에 사용)은 바뀌지 않습니다. 폴더 배너는 폴더의 커버 이미지에는 영향을 주지 않습니다([폴더 커버](#폴더-커버) 참조).

### 배너 우선순위
사용자 배너(`/_pico/banners/user/`) > 게임 코드 기반 배너(`/_pico/banners/nds/` 또는 `/_pico/banners/gba/`) > 롬 내장 배너.
폴더 배너(`banner.bnr`)는 위 우선순위와 별개로 찾습니다.

### 배너 형식
배너는 표준 Nintendo DS(i) 배너 파일이어야 합니다(보통 `.bnr` 또는 `banner.bin`이라는 이름). 정지 아이콘과 DSi 방식의 애니메이션 아이콘을 모두 지원합니다.

## 커버 이미지 (Covers)
사용자 지정 커버는 선택한 파일에 대해 상단 화면에 표시되는 `.bmp` 파일입니다. NDS/GBA 게임뿐 아니라 모든 종류의 파일에 사용할 수 있습니다.

### 게임 코드별 커버
`/_pico/covers/nds/` 또는 `/_pico/covers/gba/` 폴더에 `<게임코드>.bmp` 파일을 넣습니다. 예:
- `/_pico/covers/gba/ABCD.bmp` - 게임 코드가 `ABCD`인 GBA 게임의 커버
- `/_pico/covers/nds/EFGH.bmp` - 게임 코드가 `EFGH`인 NDS 게임의 커버

### 사용자 커버 (파일 이름별)
`/_pico/covers/user/` 폴더에 `<파일이름>.bmp` 파일을 넣습니다. 예를 들어, `myGame.nds.bmp`는 파일 이름이 `myGame.nds`인 모든 파일에 사용됩니다. 이 설정은 게임 코드 기반 커버보다 우선순위가 높습니다. DS 및 GBA 이외의 대부분의 콘솔은 게임 코드가 없으므로, 이 폴더는 NES나 GB(C)와 같은 다른 시스템 게임이나 직접 만든 홈브류 앱의 커버를 지정하는 데 적합합니다.

### 폴더 커버
커버를 지정할 폴더 안에 `cover.bmp` 파일을 직접 넣습니다. 예:
- `/GBA Games/cover.bmp` - `GBA Games` 폴더의 커버

### 커버 우선순위
사용자 커버(`/_pico/covers/user/`) > 게임 코드 기반 커버(`/_pico/covers/nds/` 또는 `/_pico/covers/gba/`) > 기본 대체 이미지.
폴더 커버(`cover.bmp`)는 위 우선순위와 별개로 찾습니다.

### 커버 형식
커버 이미지는 128x96 픽셀 크기의 **8 bpp(256색)** `.bmp` 파일이어야 합니다.
실제로는 왼쪽 상단의 **106x96 픽셀**만 사용됩니다. 오른쪽의 나머지 부분은 패딩(여백)이며 무시됩니다.

오른쪽의 검은색 부분이 사용되지 않는다는 점에 유의해 주십시오.
